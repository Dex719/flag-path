# Flag!Flag!Flag!

CTF-квест: пять пронумерованных флагов на извилистой дороге, у каждого своё задание. Верный ответ `CTF{...}` — флаг зеленеет, конфетти, дорога к соседнему взятому флагу открывается. Все пять — большое конфетти.

Ответы в коде не хранятся: в `app.js` лежат только SHA-256 хэши (`SALT:id:ответ`).

Сайт: https://dex719.github.io/flag-path/ (GitHub Pages, ветка `main`).

## Запуск локально (Linux)

Нужен Node.js 18+ (или Python 3).

```bash
npm run dev
```

Открыть http://localhost:3000

Без Node:

```bash
python3 -m http.server 3000
```

## Задания и ответы

После изменения `app.js` или `style.css` увеличь `?v=N` у подключения этих файлов в `index.html`, иначе браузеры участников до 10 минут будут брать старую версию из кэша GitHub Pages.

Тексты заданий, формат и хэш ответа — в массиве `FLAGS` в начале `app.js`.

Хэш ответа:

```bash
node scripts/hash.mjs 4 "CTF{настоящий_ответ}"
```

Для ответа-списка (как в задании 1: порядок, регистр и пробелы не важны) у флага стоит `list: true`, а хэш считается с `--list`:

```bash
node scripts/hash.mjs 1 "CTF{a,b,c}" --list
```
