# Flag!Flag!Flag!

Три красных флага на пути. Под каждым — поле для `flag{...}`. Верный ответ — флаг зеленеет, небольшое конфетти. Все три — большое конфетти.

Ответы в коде не хранятся: в `app.js` лежат только SHA-256 хэши (`SALT:id:ответ`).

## Запуск локально (Linux)

Нужен Node.js 18+ (или Python 3).

```bash
npm run dev
```

Открыть http://localhost:3000

Без Node:

```bash
python3 -m http.server 3000
```

## Поменять ответы

```bash
node scripts/hash.mjs 1 "flag{настоящий_ответ}"
```

Скопировать вывод в поле `hash` нужного флага в массиве `FLAGS` в начале `app.js`. Повторить для флагов 2 и 3.

Флаг 1 — настоящий. Флаги 2 и 3 пока тестовые: `flag{test2}`, `flag{test3}`. Перед запуском удали эту строку.

## Деплой на Vercel

```bash
npx vercel --prod
```

или импортировать репозиторий в Vercel: Framework Preset — **Other**, сборка не нужна.
